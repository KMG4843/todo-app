# CLI 파일 자동 분류기 (File Organizer)

이 프로그램은 지정된 디렉토리 내의 파일들을 확장자별로 자동 분류하고, 처리 결과를 JSON 형태의 요약 리포트로 생성하는 Python 기반 CLI 도구입니다.

## 1. 주요 기능
- **확장자별 자동 분류**: 파일 확장자명을 이름으로 하는 폴더를 생성하여 파일을 이동시킵니다.
- **예외 처리**: 존재하지 않는 경로, 권한 문제, 확장자 없는 파일 등을 안정적으로 처리합니다.
- **충돌 방지**: 대상 폴더에 동일한 이름의 파일이 있을 경우 이름 뒤에 숫자를 붙여 데이터 유실을 방지합니다.
- **결과 리포트**: 분류 완료 후 `summary.json` 파일을 생성하여 확장자별 파일 개수와 용량을 기록합니다.

## 2. 실행 방법
터미널(또는 PowerShell)에서 아래 명령어를 입력하여 실행합니다.

```bash
python organizer.py --path [대상_디렉토리_경로]
